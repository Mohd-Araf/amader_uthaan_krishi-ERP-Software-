## 📌 Project Overview
**Amader Uthaan Krishi ERP** is a full-featured Business ERP and Agro E-Commerce platform built with Django. It provides end-to-end management for order processing, inventory, customers, suppliers, automated accounting (Chart of Accounts, General Ledger, Journals, Trial Balance, Income Statement, Balance Sheet), and real-time PDF/Excel report generation.

---

## ✨ Key Features

- 🛒 **E-Commerce Shop & Order Management**:
  - Live product browsing, category filtering, search, and dynamic responsive cart.
  - Multi-unit product pricing (Kg, Grams, Pcs, Hali, Ati, Fana, Litre).
  - Instant order memo generation & PDF receipts with Asia/Dhaka local timezone.
  
- 💼 **Complete Financial Accounting ERP**:
  - Double-entry accounting system with automated journals for sales, receipts, payments, and expenses.
  - Comprehensive Chart of Accounts (Asset, Liability, Equity, Revenue, Expense).
  - Real-time General Ledgers (Customer, Supplier, Cash, Bank, Asset, Expense).
  - Trial Balance, Income Statement, and Balance Sheet with instant Excel/PDF export.
  
- 🛡️ **Admin & Staff Management Dashboard**:
  - Role-based access control (Admin, Staff/Supplier, Customer).
  - Real-time order assignment and delivery tracking.
  - Active/Inactive product status toggle (soft-delete preserved for ledger history).
  - User and account management with persistent tab state navigation.

- 📱 **100% Mobile Responsive Design**:
  - Fully responsive tables, cards, and navigation designed for seamless smartphone experience without horizontal scrolling.

## 🚀 Technology Stack
- **Backend**: Python, Django
- **Database**: SQLite (Development) / PostgreSQL (Production)
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap, FontAwesome
- **Reporting**: ReportLab (PDF Generation), OpenPyXL (Excel Export)
- **Deployment**: Render / Gunicorn / WhiteNoise
